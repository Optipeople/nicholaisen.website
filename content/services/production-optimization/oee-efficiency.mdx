## OEE is not the goal

OEE is a thermometer, not a treatment. We have seen plants chase the number without asking whether the number is meaningful. They game the planned-downtime category, they exclude the last hour of the shift, they redefine the denominator every quarter.

The point of an OEE program is not to make the number go up. It is to give the team a credible signal so the right improvements get prioritized. If the signal is honest, the number tends to go up by itself.

## What good looks like

A good OEE program produces a number the operators trust, the team leaders use, and the plant manager presents to the board with a straight face. The same number, with the same definition, every week. Boring, in the best possible way.
