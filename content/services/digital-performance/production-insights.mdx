## Designed for the shop floor

Most production insight platforms are built for the manager and adapted for the operator. Opti is built the other way around. The first user we design for is the operator who has to classify a stop in the middle of running three machines. If the interface is wrong for them, every downstream report is wrong.

## Honest by default

Opti reports availability, performance and quality with explicit definitions and visible assumptions. When a number on the dashboard does not match what the operator saw, the system flags the discrepancy instead of averaging it away. We have seen too many platforms that hide their assumptions; we built Opti to surface them.
